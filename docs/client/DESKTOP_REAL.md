# 真实桌面连接开发版

2026-10-10。按用户明确要求，将已验证的生产 TUN 接入桌面。当前是开发联调入口，不等于正式安装包或完整 M0′/C1 验收。

## 当前机器如何操作

1. 双击仓库根目录 `启动生产客户端.cmd`。第一次安装或代码/资源更新时接受 Windows UAC；服务已运行且版本未变时复用，不重复安装。保留开发启动窗口。
2. 界面顶部必须显示“真实连接开发版”。若显示“开发演示”，连接不会改变出口，不能用它检查代理。
3. 选择全局模式，点击“快速连接”，或从真实可用国家列表选择国家。等待“已连接”后再刷新浏览器的公网 IP 查询页面。
4. 点击“断开连接”，等待网络恢复和“尚未连接”。正常关闭真实桌面窗口也会请求断开并等待清理；托盘和后台运行策略尚未交付。

开发版已接入登录表单和账号摘要。点击左下角“登录账号”，输入邮箱密码；登录后查看套餐、有效期和设备数量。已有登录会话自动保留。点击“退出本机登录”会先断开并清理本机令牌。操作与边界见 [ACCOUNT.md](ACCOUNT.md)。测试启动器仍为明确演示，未把测试证书绕过带入生产。

## 实现与安全边界

入口 `apps/desktop/tools/desktop-real.ps1` 读取忽略的 `.local/desktop-production.json`，只要求 `control`，旧 `account` 字段不再使用；不提交真实环境配置。安装脚本核验固定资源及构建摘要，复制到受 SYSTEM/管理员 ACL 保护的 ProgramData 专属目录。安装创建手动启动的 `LightflowDesktopDev` Windows Service；没有设置开机自启。重启后若服务未运行，开发启动器需要 UAC 启动/配置服务。

服务接收桌面密码输入后，只用 DPAPI LocalMachine 保存令牌和持久设备私钥，结合 SYSTEM/管理员文件 ACL 与唯一控制用户 SID 的 IPC ACL。不保存密码，普通断开保留设备；本机退出保留无令牌身份档案，重新登录复用原设备。

安装目录及资源所有者固定为 SYSTEM，子项按根目录精确 ACL 继承，并在启动服务前复核全部安装资源 hash，避免交互用户作为文件所有者改写服务。实测普通桌面用户直接打开服务会话文件返回拒绝访问；这不代替跨用户完整攻击测试。

Rust 在发送指令前核对管道服务端 PID 与 SCM 中登记的服务 PID。真实管道仅允许配置用户和 SYSTEM，go-winio 拒绝远程客户端。UI/Rust 不获得令牌、设备私钥、代理凭据或核心配置，也不能传任意程序/文件路径。

连接通过服务启动固定 Mihomo TUN，系统 fake-IP DNS、真实域名 HTTPS 和租约 activate 成功后才发布“已连接”。取消提升 generation，等待停止核心、释放租约和网络恢复，期间拒绝第二次连接。未确认释放的会话保留服务私有标记，禁止新建租约绕配额。

持续会话按服务端周期续租，并在访问令牌临近到期时串行刷新、原子保存。发送刷新请求前先持久记录旧刷新令牌已消费；响应不确定时要求重新登录，不重放旧令牌。核心/转发检查或续租失败时退出并清理。服务及核心由 Job Object 管理。交互桌面会话不抓用户流量、不保存原始核心日志，只保留安全错误码。

本机 IPC v1 的真实管道增加 `disconnecting` 状态和可选 `last_error`，同步 Go/TS/schema；Rust 使用类型化方法转发及安全 JSON 快照。演示仍使用原管道和显式 simulation 标志，真实入口不可静默回退到演示。

## 已验证与未完成

实机通过与桌面按钮相同的 IPC 发起连接/断开：真实状态 `simulation=false`，普通用户无应用代理的 HTTPS 查询出口切换为网关出口；断开后恢复原直连出口，服务无错误，TUN 清理。最初资源漏装和取消提前杀核心导致的清理竞态已修复并复测。

Rust 实机测试通过真实服务身份与快照；Go 单测覆盖旧回调不能复活连接、清理期间拒绝新连接、失败不显示已连接、刷新令牌消费/轮换和两轮定时续租。Windows Go test/vet、前端 build/test、Rust check 通过；Linux 编译/测试交叉编译通过，不是 Linux 运行验收。

用户已确认基本桌面连接测试通过，登录/订阅功能已实现并通过真实服务 IPC 与浏览器契约测试。尚未完成：账号各异常分支真人验收、真实长期跨两次续租及 token 刷新、有效抓包和完整 DNS/IPv6 防泄漏、国内分流、切网/睡眠/服务崩溃恢复、跨用户攻击测试、VLESS 回退、正式安装卸载/更新/签名、托盘和 Kill Switch。连接开发入口可用，不能声称生产 VPN 已完成安全交付。
