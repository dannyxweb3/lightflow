# 桌面登录、订阅与本机退出

2026-10-10。客户端待办第 3 项的实现与验收记录；云端契约仍以 `docs/API.md`、`docs/openapi.json` 为准。

## 用户操作

双击“启动生产客户端.cmd”，点击左下角“登录账号”。输入邮箱和密码，点击“登录”。成功后显示邮箱、套餐、有效期、设备数量/上限、同时连接上限和最近更新时间；返回连接页选择国家或快速连接。已保存登录状态的用户直接进入应用，不必每次登录。

点击“退出本机登录”会先取消连接并等待核心停止、租约释放及网络恢复，再删除本机令牌。其他设备保持登录。同一账号重新登录复用原设备身份，普通退出不删除云端设备。换账号先退出本机登录；身份按固定控制面和服务端账号 ID 隔离。设备撤销后不静默生成新身份绕过撤销，设备删除/重置操作留待后续明确交互。

断开后可点击“刷新账号信息”。连接期间暂禁用刷新，避免服务和会话工作进程并发轮换同一刷新令牌。账户页时间为本机时区，最近更新时间说明摘要的新鲜度；连接授权及续租仍由服务器检查实际权益。未登录、订阅禁用或到期拒绝新连接。

## 实现与秘密边界

- 真实 IPC v1 新增 `login`、`logout`、`refresh_account`，`snapshot.account` 只含公开摘要；演示模式拒绝账号操作。同步 Go/Rust/TypeScript/schema，旧模拟快照可以没有 `account`。
- 登录异步接受，`account.busy` 表示处理中；快照轮询报告完成或安全错误。连接与账户操作串行，退出期间阻止新连接；旧 generation 不得恢复连接。
- 密码使用未受控输入，提交时立即清空 DOM；不进入 React state、React Query mutation/cache、配置文件或日志。输入仅短暂经受服务身份验证的白名单 IPC 交给服务；进程内不可变字符串不承诺可验证的物理内存擦除。
- Go 服务使用固定 HTTPS 控制面登录，读取 `/v1/me`、注册持久设备、查询 `/v1/devices` 与 `/v1/countries`。访问/刷新令牌、密钥及摘要用 DPAPI 保存，配合 SYSTEM/管理员 ACL 和控制用户 SID 的管道权限。
- 注册请求前先保护保存设备密钥，避免丢失注册响应后生成重复设备。退出保留按账号隔离、没有令牌的受保护身份档案，删除活动登录会话。刷新令牌消费与轮换沿用服务私有原子存储。
- 不调用云端 `/v1/auth/logout`：当前契约会撤销全账号会话和租约。当前本机退出没有服务端单会话撤销能力；删除本机令牌不会提前撤销其服务端有效期。该接口缺口记录在客户端服务端请求中。
- 未确认释放的租约或网络恢复失败时，退出返回错误并保留恢复所需身份，不伪装退出成功。

## 开发入口变化

开发启动器的忽略配置只要求 `control`，不再要求账号文件；安装/更新只配置服务，不自动重新登录。旧配置里的 `account` 字段忽略。已有受保护会话保留，服务启动时异步刷新摘要；全新安装显示登录表单。手动启动服务的策略不变，未新增开机自启。

旧 `-provision -account` 仅保留为历史联调入口，常规桌面启动不调用。测试启动器仍是显式模拟，不能据此声称测试服务器的真实登录/连接已接入。

## 验证范围

Windows Go 单测覆盖未登录/过期订阅拒绝连接、登录异步与重复请求、缓存不含明文密码、退出等待隧道清理、待释放租约阻止退出、DPAPI 身份档案不含令牌且保留设备密钥。前端浏览器契约测试覆盖密码提交后清空、账号与订阅显示、本机退出；它使用明确的 IPC mock，不代替 Windows 真人验收。

生产实机通过真实服务 IPC 完成本机退出、重新登录和账号刷新，同账号重新登录设备数量未增加。网络回归与最终检查见 `M0_EVIDENCE.md`。开发验收脚本 `apps/desktop/tools/test-desktop-account.ps1` 从本机文件读测试凭据，先验证管道服务端 PID 与 SCM 服务一致，不在参数或输出中传密码。

仍待专项验证：账号撤销/订阅变化在长期连接中的所有分支、断网/限流/响应丢失的完整真人体验、不同账号切换和跨 Windows 用户攻击测试。设备列表管理、删除设备、全账号退出未在本轮开放。
