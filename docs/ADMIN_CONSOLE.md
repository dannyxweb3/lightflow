# 管理后台功能文档（首版）

## 目标与使用者

为单个运营管理员提供浏览器界面，完成账户开通、订阅调整和节点维护，减少直接调用管理 API 的日常操作。首版适用于受控管理网络或 SSH 隧道，不面向公网开放。

## 页面与功能

| 页面 | 首版功能 |
| --- | --- |
| 登录 | 独立管理员密码登录、8 小时会话、退出登录；失败登录限流 |
| 概览 | 用户总数、活跃/待确认租约数、可用/总节点数 |
| 用户与订阅 | 按邮箱搜索，每页最多 50 条；创建用户；查看订阅、最近 100 条设备与连接；修改套餐、到期时间、设备/并发上限及订阅开关 |
| 国家 | 查看国家；新增国家或修改显示名称 |
| 节点 | 查看地址、国家、就绪状态和最近确认时间；新增协议入口；启停节点 |

修改订阅会撤销该用户现有连接。停用节点会撤销该节点的现有连接。页面在提交前提示影响，服务端负责最终执行。新增节点时需提供与网关 Agent 一致的独立令牌；后台不会显示已有令牌。

## 权限和边界

管理密码仅用于后台登录，浏览器不接收 `ADMIN_KEY`。后台使用数据库中的短期会话、HttpOnly/SameSite Cookie 和写操作 CSRF 校验。管理 API 的原有 `ADMIN_KEY` 接口继续供受控脚本使用。应用仍只监听 HTTP；Nginx/Cloudflare 负责外部 HTTPS，必须限制管理路径访问来源。生产配置保持 `ADMIN_COOKIE_SECURE=true`。

首版是**单管理员**界面，没有 MFA、多管理员角色、精细审计或密码自助重置，因此应仅通过 SSH 隧道或受控管理网络访问；若需要公网管理入口，先接入具备 MFA 的外部身份访问层。管理会话及口令独立于普通用户身份。

## 暂不包含

用户设备/连接的管理端强制撤销、国家停用、网关令牌轮换界面、策略/安装包发布、健康趋势图、多管理员 RBAC、MFA 和审批流。对应功能需要补充专门接口和操作审计后再开放；不通过浏览器直接连接数据库。

## 验收要点

1. 无管理会话无法读取后台数据；错误密码、跨站写请求和缺少 CSRF 的写请求被拒绝。
2. 创建用户后可搜索并查看；修改订阅后旧连接被撤销。
3. 节点停用后不再被新连接选中；概览的可用节点数随网关确认状态变化。
4. 管理页面和 `/console/api/*` 只经受限管理入口访问，公开 API 入口继续只放行 `/v1/*` 与健康检查。
